# Python com Guanabara

Repositório dedicado aos exercícios de Python que estou aprendendo com **Gustavo Guanabara** do **Curso em Video**.

## 📚 Sobre

Este repositório contém exercícios práticos e projetos desenvolvidos durante o curso de Python com Guanabara. Aqui você encontrará diversos exemplos de código, desde conceitos básicos até tópicos mais avançados.

## 🎯 Objetivo

Documentar meu progresso no aprendizado de Python e compartilhar soluções de exercícios para fins educacionais.

## 💻 Conteúdo

- Exercícios de lógica de programação
- Estruturas de dados
- Funções e modularização
- Manipulação de arquivos
- Projetos práticos

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/Gabriellabneves/Python-com-Guanabara.git
```

2. Navegue até a pasta desejada e execute os scripts Python:
```bash
python nome_do_arquivo.py
```
